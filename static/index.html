CONTROL PANEL

Make it yours.

Say “Hey Jarvis” to start a conversation. Speak normally and pause to send each turn; say “Thank you Jarvis” by itself to finish. After 12 seconds of silence, JARVIS checks in once. Wake detection and transcription stay on this computer. Recognised text goes to the configured assistant provider. Wake detection pauses during replies. With headset hands-free interruption enabled, sustained microphone sound interrupts playback in an open conversation. Browser echo cancellation helps, but loud background noise or speaker leakage can trigger it; disable this option in Settings if needed. Hold to talk remains available. Mute or Stop turns the microphone off. Browser microphone permission is required.

ADD KEYS LOCALLY

Put them in the key file config\.env of your JARVIS installation (normally %LOCALAPPDATA%\JARVIS\config\.env). Add OPENAI_API_KEY (or DASHSCOPE_API_KEY for Qwen) and set JARVIS_PROVIDER to openai or qwen. Add FISH_API_KEY and FISH_VOICE_ID for your Fish Audio voice. Restart JARVIS to load changes.

Spotify uses SPOTIFY_CLIENT_ID and browser sign-in. Keys never go in this interface or chat.
